# Verification reports

One report per verification spec (`<VER-ID>.md`) plus phase-gate reports (`phase-<k>.md`), kept
by the verifier (docs/verification-policy.md §6). Each report states the inputs, a results table
with observed errors next to the tolerances, the solver(s), the environment (opentcad, DEVSIM,
MKL versions) and the commit it was produced from.
